## Sections

### Connecting your own GitHub organization

By default, Major hosts your app repositories using Major's GitHub infrastructure. Organizations can now link their own GitHub App installation instead, which gives you direct control over repository management.

To connect your GitHub organization, go to **Settings → GitHub App** in the web dashboard. If your organization is currently using Major's GitHub, you'll see an amber notice recommending you link your own GitHub organization for improved speed and security.

Once you connect your own GitHub organization, Major automatically stops using its shared GitHub hosting for that organization. New repositories and push events will route through your GitHub App installation.

Apps created while Major's GitHub hosting was active keep a **Uses Major Github** badge in the dashboard to distinguish them from apps using your organization's own GitHub.

### GitHub webhook integration

Major now listens for GitHub push events via a webhook endpoint. When commits are pushed to your main branch, Major uses this to trigger downstream workflows such as build and deployment pipelines.

To use this, configure your GitHub App (or Major's shared app) to send push events to Major. Webhook requests are authenticated with HMAC-SHA256 signature verification.

### Automatic query extraction

When commits land on your main branch, Major scans your TypeScript/JavaScript source code and catalogs every SQL query it finds. Extracted queries are linked to the resource they target and stored automatically — you don't need to annotate your code.

#### Viewing and editing queries in the editor

Open your app in the web editor and select the **Queries** panel. Queries are grouped by resource and show metadata including invocation keys and file locations. You can edit query strings directly from this panel.
