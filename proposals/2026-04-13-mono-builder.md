## Sections

### Bring Your Own GitHub App

Organizations can now connect their own GitHub App instead of relying on Major's shared GitHub infrastructure. This gives your organization faster access and greater control over repository permissions.

**To connect your GitHub App:**

1. Go to **Settings → GitHub App** (`/settings/github-app`).
2. Follow the prompts to install and link your GitHub App to your Major organization.

Once connected, Major uses your organization's GitHub App tokens automatically — including refreshing them when needed. You can disconnect at any time from the same settings page, which reverts your organization to Major's hosted GitHub.

When your organization uses Major's GitHub, an amber notice appears on the GitHub App settings page prompting you to link your own GitHub organization for better speed and security.

> **Note:** When you connect an external GitHub account or organization, Major automatically marks your organization as no longer using Major's hosted GitHub. You do not need to change this manually.

### Automatic Query Extraction

Major now scans your application's source code for SQL queries whenever code is pushed to the main branch. Discovered queries are stored and associated with the relevant resource.

For each query, Major records:

- The query string
- The method name and file location where it appears
- Any parameters used
- The associated resource

You can browse all discovered queries in the new **Queries panel** in the editor (see below).

---

### Queries Panel in the Editor

The app editor now includes a **Queries** tab (marked with a `#` icon) alongside Chat, Source Control, and Settings. Open it to see every SQL query discovered in your application's codebase.

In the Queries panel you can:

- View queries grouped by resource
- Expand any query to see its full string, method name, file location, and invocation keys
- Edit individual query strings inline

The panel fetches data from the `/queries/list` endpoint, which returns all queries for the current application.

---

### GitHub Webhook Integration

Major's API now listens for GitHub push events on your main branch via a `POST /github/webhook` endpoint. Webhook signatures are authenticated automatically. When a push arrives, Major triggers the query extraction workflow described above.

No action is required on your part beyond connecting your GitHub App or using Major's hosted GitHub — the webhook is configured automatically.
