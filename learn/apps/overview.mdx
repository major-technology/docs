An **app** is a self-contained project you build, deploy, and share through Major. Use the AI-powered [web app](/learn/web-app) or your own tools through the [MCP](/build/mcp) and [CLI](/build/cli) to develop it, [deploy](/learn/apps/deploying) it to production, configure [environments](/learn/apps/environments) for staging and production, and [share](/settings/members-and-roles) it with your team.

## Lifecycle

1. **Create** - Build with the Platform Agent, the MCP, or the CLI.
2. **Connect** - Attach [connectors](/learn/connectors/overview) (databases, APIs).
3. **Deploy** - Ship to production with one command or click.
4. **Share** - Grant access to teammates with [roles](/settings/members-and-roles).

## Source control

Every app is backed by a Git repository. Major hosts repositories by default, but you can connect your own GitHub organization at any time. Either way, the code is yours - clone, branch, and manage it with any Git tooling.
