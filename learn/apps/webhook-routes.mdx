---
title: "Webhook routes"
description: "Receive raw, unauthenticated HTTP callbacks from external services in your app."
---

Receive HTTP callbacks from external services (Stripe, GitHub, Twilio, etc.) by creating routes matching `/api/webhook/*` and turning on **Webhook Access** in your app's settings. When enabled, only `/api/webhook/*` routes are publicly accessible - all other routes remain protected.

<Tip>
If you want an external event to start work in Major, use a [webhook trigger](/learn/triggers/webhooks) instead. Webhook triggers start a workflow and every call is authenticated with a credential, so they are the more secure and preferred option. Use webhook routes only when a service must post raw payloads to your app and can't send a credential.
</Tip>

## Setup

Create a route in your app's backend under the `/api/webhook/` path. The backend already serves everything under `/api`, so a route at `/webhook/stripe` answers `/api/webhook/stripe`:

```typescript
// backend/src/routes/webhooks.ts
import { createRoute, z, type OpenAPIHono } from "@hono/zod-openapi";

const stripeWebhookRoute = createRoute({
  method: "post",
  path: "/webhook/stripe",
  responses: {
    200: { description: "Received", content: { "text/plain": { schema: z.string() } } },
  },
});

export function registerWebhookRoutes(app: OpenAPIHono) {
  app.openapi(stripeWebhookRoute, async (c) => {
    const body = await c.req.text(); // the raw body, for signature checks
    // Verify and handle the webhook payload
    return c.text("OK", 200);
  });
}
```

Register it in `backend/src/app.ts` with `registerWebhookRoutes(app)`. In a Next.js app, put the handler in `src/app/api/webhook/stripe/route.ts` as `export async function POST(request: Request)`.

## Security

Best practice is to verify webhook signatures to ensure requests come from the expected source. Most services (Stripe, GitHub, etc.) include a signature header that you can validate against a shared secret.
