Agent coding sessions can run on multiple AI providers — Anthropic, OpenAI, Google Gemini, and Kimi. Multi-model is available to all organizations with no special enrollment required. For the full list of models by capability tier and relative cost, see [Models](/getting-started/core-concepts/models).

## Agent model locking

When an agent has a model configured, all chats bound to that agent lock to that model — users cannot change it from the picker. This keeps every run of a published agent on the same model.
