This page lists the connectors you can add to your organization. For how connectors work, how credentials are stored, and how to set one up, see [Connectors](/learn/connectors/overview).

## Authentication modes

The **Auth** column shows how each connector can authenticate:

- **Shared** - one set of credentials for everyone. Every app user and agent run uses the same account.
- **Per-user** - each person signs in with their own account through OAuth, so they only reach data they are entitled to. People manage these accounts from [Connected Accounts](/settings/connected-accounts).
- **Identity** - Major assumes a cloud identity you create in **Settings > Identities** (an AWS IAM role or a GCP service account) instead of storing long-lived keys.

See [Shared vs. per-user connections](/learn/connectors/overview#shared-vs-per-user-connections) for details.

<Note>
Don't see what you need? Use [Custom API](#generic-and-custom), [GraphQL](#generic-and-custom), or a [custom MCP server](#generic-and-custom), or click **Request it** in the Add Connector dialog.
</Note>

## Generic and custom

| Connector | Description | Auth |
| --- | --- | --- |
| Custom API | Call any REST API. Major injects the auth headers you configure. | Shared |

## Catalog connectors

In addition to the connectors above, the Add Connector dialog includes a catalog of more than 200 additional apps, such as Jira, Confluence, Asana, Airtable, monday, ClickUp, Zoom, Intercom, Gong, RingCentral, Shopify, Xero, Pipedrive, Greenhouse, Box, Dropbox, Google Ads, Datadog, Sentry, and GitLab. Search the dialog to find one. Catalog connectors use shared authentication and are reached through the [HTTP proxy](#generic-and-custom).

| Major Auth | Share or revoke access to an app for users by email. See [Authentication](/learn/apps/authentication). | Managed by Major |
| AI proxy | Add LLM calls and chat features to an app without your own model API keys. See [AI proxy](/learn/apps/ai-proxy). | Managed by Major |
