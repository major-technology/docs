In a [Platform Agent](/build/platform-agent) chat, people choose a tier, not a model. Admins decide which model each tier runs on in **Settings > Models**.

| Tier | Default model | Use it for |
| --- | --- | --- |
| **Smartest** | Opus | Deepest reasoning. |
| **Balanced** | Sonnet | The best everyday default. |
| **Fastest** | Haiku | Quick, inexpensive tasks. |

## Change a tier's model

1. Open **Settings > Models**.
2. Next to a tier, open the model picker and choose any model from the [catalog](/learn/agents/models#available-models).

The change applies to your whole organization. A tier you haven't changed keeps using its default. People in chat see only the tier names, never the model behind them.

<Note>
Tiers apply to Platform Agent chats. [Agents](/learn/agents/models) each use the model set on the agent.
</Note>

“Supported in AI Proxy” means the model is in Major's allowed catalog. Requests must use an operation supported by that model, and upstream provider availability still applies. Legacy proxy routes remain in the catalog for compatibility; the proxy does not automatically redirect those requests to a successor.

“Supported in Chat & Agents” means the model is eligible for those runtimes. The picker presents stable families and capability tiers rather than listing every concrete version. Older selections can remain valid even when they are no longer offered in the picker.

For sessions using the Pi harness, saved Claude Opus 4.8, Sonnet 4.6, and Haiku 4.5 selections run on their 5.5 successors. Other harnesses preserve those pinned Claude versions. Saved Kimi K2 selections run on Kimi K3 in both harnesses.

## Using proxy-only models


Proxy-only models are available to applications through the [AI proxy](/learn/apps/ai-proxy), not as chat or agent model selections.

- **Embeddings:** call `/openai/v1/embeddings` with `text-embedding-3-small` or `text-embedding-3-large`.
- **Decisions:** call `/typesafe/v1/systemone` with `jev-1.13.0`, or use Bifrost's `/v1/decisions` format with `typesafe/jev-1.13.0`.
- **Images:** use the OpenAI image generation or editing endpoints with `gpt-image-1`.
- **Speech:** use the OpenAI speech endpoint with `tts-1` or `tts-1-hd`.
- **Transcription:** use the OpenAI transcription endpoint with `whisper-1` and a multipart file upload.

Use the model ID shown above on its native provider endpoint. For cross-provider requests, the routing prefixes are `anthropic/`, `openai/`, `gemini/`, `xai/`, and `typesafe/`. Kimi and MiniMax are served through Fireworks:

| Model | Cross-provider route |
| --- | --- |
| `kimi-k3` | `fireworks/accounts/fireworks/models/kimi-k3` |
| `kimi-k2.7-code` | `fireworks/accounts/fireworks/models/kimi-k2p7-code` |
| `kimi-k2.6` | `fireworks/accounts/fireworks/models/kimi-k2p6` |
| `minimax-m3` | `fireworks/accounts/fireworks/models/minimax-m3` |

All inference requires an authorized Major token, enabled proxy access where applicable, and available spending capacity. Usage is metered through Major's existing billing.
