The web dashboard lets you configure and manage connectors for your organization. For detailed documentation on each connector type, see the [Connectors](/connectors) section.

## Adding a connector

1. Click **Add Connector** in the Connectors page
2. Select the connector type from the list
3. Complete the configuration and authentication (some connectors use OAuth)
4. Click **Save**

If you don't see the connector you need, click **Request it** to submit a feature request.

## Using connectors in apps

In the App Editor, you can bind pre-configured connectors to your application. The platform handles the secure connection and authentication automatically.

The AI assistant will automatically generate and use resource clients when you ask it to interact with your connectors.

## Per-environment configuration

When editing a connector, you can configure each environment independently. This lets you use different credentials or endpoints for staging and production.

| Environment | Host | Database |
| --- | --- | --- |
| default | prod.example.com | myapp_prod |
| staging | staging.example.com | myapp_staging |

To configure:
1. Click on a connector to edit it
2. Select the desired environment
3. Enter the connection details for that environment
4. Click **Save**

## API Tokens

Programmatically access invocation data from your connectors and resources using API tokens. Create and manage tokens in the **API Tokens** settings page.

### Creating a token

1. Go to **Settings** > **API Tokens**
2. Click **Create Token**
3. Give the token a name (for your reference)
4. Copy the token immediately — you won't be able to see it again

Tokens are prefixed with `MJR_` and scoped to your organization.

### Using API tokens

Include your token in the `Authorization` header with the `Bearer` scheme:

```bash
curl -H "Authorization: Bearer MJR_your_token_here" \
  https://api.major.build/api/public/invocations
```

API tokens grant access to public API endpoints for reading invocation data. Admins can create and revoke tokens; organization members can view the tokens that exist.
