The Major web dashboard is the control center for your internal tools. While the CLI handles local development, the web dashboard is where you collaborate, manage permissions, and ship to production.

## Core capabilities

Create apps with a natural-language description using the Quick-Start feature. The system auto-generates an app name and description, creates the app, and opens the editor with your initial request queued in the chat. Edit apps in a live session, preview changes instantly, and leverage AI assistance. Access a redesigned dashboard with floating app island, search, tabs, and animated background.
