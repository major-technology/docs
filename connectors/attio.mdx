Connect to Attio CRM to access people, companies, deals, and lists through Major's connector system.

## Setup

Attio supports two authentication modes:

- **OAuth** — connect via Attio's OAuth flow with configurable scopes
- **API Key** — enter your Attio API key directly

Select your preferred mode when creating the connector.

## MCP Tools

| Tool | Description |
| --- | --- |
| `mcp__resources__attio_get` | Fetch a single record by ID. |
| `mcp__resources__attio_list_objects` | List available object types (people, companies, deals). |
| `mcp__resources__attio_list_records` | Query records of a given object type. |
| `mcp__resources__attio_list_lists` | List Attio lists. |
| `mcp__resources__attio_invoke` | Call any Attio API endpoint. |

## TypeScript Client

Major generates a typed `AttioResourceClient` in your app's `src/clients/` directory.
