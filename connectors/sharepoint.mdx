---

Connect to Microsoft SharePoint and OneDrive for Business via the Microsoft Graph API to browse sites, access lists, and manage documents.

## Setup

Connect via Microsoft OAuth when creating the connector.

## MCP Tools

| Tool | Description |
| --- | --- |
| `mcp__resources__sharepoint_list_sites` | List SharePoint sites. |
| `mcp__resources__sharepoint_get_site_items` | Get lists and libraries in a site. |
| `mcp__resources__sharepoint_search_drive_items` | Search files and folders across drives. |
| `mcp__resources__sharepoint_invoke` | Call any Microsoft Graph API endpoint. |

The connector also supports generating presigned download URLs for files and uploading content to drives.

## TypeScript Client

Major generates a typed client in your app's `src/clients/` directory.
