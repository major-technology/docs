Connect to the Fireflies AI meeting transcription API to query transcripts, list participants, retrieve summaries, and upload audio for transcription.

## Setup

When creating the connector, enter your Fireflies **API Key**.

## MCP Tools

| Tool | Description |
| --- | --- |
| `mcp__resources__fireflies_list_transcripts` | List recent meeting transcripts. |
| `mcp__resources__fireflies_get_transcript` | Fetch a transcript by ID including full text. |
| `mcp__resources__fireflies_list_users` | List users in your Fireflies workspace. |
| `mcp__resources__fireflies_query` | Execute a raw GraphQL query against the Fireflies API. |

Additional tools support audio upload and summary retrieval.

## TypeScript Client

Major generates a typed client in your app's `src/clients/` directory.
