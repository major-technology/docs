Connect to Google Search Console to query search performance data, inspect URLs, list verified properties, and manage sitemaps.

## Setup

Connect via Google OAuth when creating the connector. Select the scopes you need — read-only or read-write access to Search Console data.

## MCP Tools

| Tool | Description |
| --- | --- |
| `mcp__resources__googlesearchconsole_list_sites` | List verified Search Console properties. |
| `mcp__resources__googlesearchconsole_get_site` | Fetch a single verified property. |
| `mcp__resources__googlesearchconsole_query_analytics` | Query search traffic by query, page, country, or device. |
| `mcp__resources__googlesearchconsole_inspect_url` | Inspect a URL's indexing status and issues. |
| `mcp__resources__googlesearchconsole_list_sitemaps` | List submitted sitemaps for a property. |
| `mcp__resources__googlesearchconsole_invoke` | Call any Search Console API endpoint. |

## TypeScript Client

Major generates a typed client in your app's `src/clients/` directory.
