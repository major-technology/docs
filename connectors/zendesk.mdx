Zendesk connects via Pipedream Connect — Major manages the OAuth flow in your organization's Pipedream workspace.

## Setup

1. In the **Add Connector** dialog, select **Zendesk**.
2. Authenticate your Zendesk account through Pipedream's hosted OAuth UI.
3. Save the connector.

If an OAuth token expires, a **Reconnect OAuth** button appears next to the **Test Connection** button in the connector settings sheet.

## MCP Tools

Use the generic HTTP proxy tools to call any Zendesk API endpoint:

| Tool | Description |
| --- | --- |
| `mcp__resources__http_proxy_get` | GET request to a Zendesk API path. |
| `mcp__resources__http_proxy_invoke` | POST, PUT, PATCH, or DELETE to a Zendesk API path. |

OAuth credentials are injected automatically. Common paths include `/api/v2/tickets`, `/api/v2/users`, and `/api/v2/search`.
