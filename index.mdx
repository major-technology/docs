Major is a platform for building apps, agents, skills, and workflows on top of your company's data. You connect your databases, SaaS tools, and APIs once as [connectors](/learn/connectors/overview). Everything you build on Major uses those connectors securely, with access controlled per user.

You describe what you want, an AI agent builds it in a sandbox, you preview it, and you deploy it to your team.

## Three ways to build

<CardGroup cols={3}>
  <Card title="Platform" icon="browser" href="/build/platform-agent">

  </Card>
  <Card title="MCP" icon="plug" href="/build/mcp">

  </Card>
  <Card title="CLI" icon="terminal" href="/build/cli">

  </Card>

All three use the same platform. Apps, agents, and connectors you create in one are available in the others.

## No secrets in your code

Connectors are configured once in Major. Your code uses generated clients that authenticate through the Major platform, so there are no connection strings, API keys, or `.env` files to manage. The same code works in the sandbox, locally, and in production.

```typescript
// No connection strings, no API keys, no .env files
import { myDatabaseClient } from './clients';

const result = await myDatabaseClient.invoke(
  'SELECT * FROM users WHERE id = $1',
  [userId],
  'fetch-user'
);
```

Connectors can use one shared account or let each person sign in with their own account, so every user only reaches the data they are allowed to see. See [Connectors](/learn/connectors/overview) for details.
