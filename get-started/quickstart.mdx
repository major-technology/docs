This guide connects your AI client to Major and walks you through building and deploying your first app.

<Tip>
Don't use an AI client? Go to [app.major.build](https://app.major.build), sign in, and describe what you want to the [Platform Agent](/build/platform-agent). You can skip to [Step 2](#step-2-build-something).
</Tip>

## Step 1: Install the Major plugin

The Major plugin adds the Major MCP server (`https://mcp.major.build/mcp`) and the Major skills to your client. Pick your client:

<Tabs>
  <Tab title="Claude Code CLI">
    <Steps>
      <Step title="Install the major plugin">
        Run this command in your terminal. The plugin comes from the Anthropic plugin directory, which is built into Claude Code.

        ```bash
        claude plugin install major@anthropic-plugin-directory
        ```
      </Step>
      <Step title="Sign in to Major">
        Your browser opens the Major sign-in page. Sign in and accept the access request.

        ```bash
        claude mcp login plugin:major:major
        ```
      </Step>
      <Step title="Make sure that the server is connected">
        The "plugin:major:major" server shows the URL `https://mcp.major.build/mcp` and the status "Connected".

        ```bash
        claude mcp list
        ```
      </Step>
      <Step title="Test the connection">
        Start Claude Code and ask a question about your Major workspace.

        ```bash
        claude
        ```

        ```text
        List my Major apps.
        ```
      </Step>
    </Steps>

    <Note>
    You can also install the plugin inside a Claude Code session: `/plugin install major@anthropic-plugin-directory`.
    </Note>
  </Tab>
  <Tab title="Codex CLI">
    <Steps>
      <Step title="Add the Major plugin marketplace">

        ```bash
        codex plugin marketplace add major-technology/cli
        ```

      <Step title="Install the major plugin">

      <Step title="Sign in to Major">

      <Step title="Make sure that the server is connected">


      <Step title="Test the connection">
        Start Codex and ask a question about your Major workspace.

## Step 2: Build something

Describe the app you want and name the system its data lives in. For example:

```text
Build me an app that shows open deals by stage and owner from my HubSpot, with a filter for close date.
```

Here is what happens next:

<Steps>
  <Step title="Connector setup">
    If the connector you named isn't set up yet, you get a setup card (or a link, in an AI client). Open it, connect the account, and the build continues. See [Connectors](/learn/connectors/overview).
  </Step>
  <Step title="Sandbox">
    The agent creates the app and writes the code in a cloud sandbox. It reads the connector's schema and context documents so the queries match your data.
  </Step>
  <Step title="Preview">
    You get a live preview URL of the running app. Ask for changes in plain language and the preview updates.
  </Step>
  <Step title="Deploy">
    When it looks right, ask the agent to deploy. The app gets a production URL that you can share with your team. See [Deploying](/learn/apps/deploying).
  </Step>
</Steps>

For more ideas, see [Use cases](/get-started/use-cases).
